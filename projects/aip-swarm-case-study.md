# AIP Swarm Case Study

공개 case study: [spongebobDG/aip-swarm-case-study](https://github.com/spongebobDG/aip-swarm-case-study)

## 해결하려던 문제

ROS 2 기반 군집 순찰 프로젝트에서 여러 차량의 상태와 카메라 정보를 중앙에서 확인하고, 서브 차량이 명령에 따라 움직일 수 있는 기능을 구현했습니다.

## 본인 기여

- 카메라 비전 파이프라인
- 웹 관제 화면과 서버 기능
- 서브 차량 구동 연동

## 공동·팀 시스템

Gazebo, Nav2, FastDDS, `gz_ros2_control`, 열화상 순찰 등 전체 시스템은 팀 결과입니다. 해당 영역의 존재와 인터페이스는 설명할 수 있지만 개인 구현으로 주장하지 않습니다.

## 기여 추적의 한계

원본 저장소의 다수 커밋이 공용 `AIP Team` 저자로 기록되어 개인별 commit count만으로 기여를 증명하기 어렵습니다. 따라서 공개 문서에서는 담당 기능·경계·비소유 영역을 명시하고, 면접에서는 담당 코드와 기술적 판단을 설명합니다.

## 한계와 다음 개선

- 전체 팀 코드는 비공개 원본에 유지합니다.
- 공개 승인을 받은 문서와 설명만 우선 공개했으며 코드·영상은 팀 합의 범위가 확인된 자료만 추가합니다.

## 면접 답변

- **30초:** “군집 로봇 전체를 혼자 만들었다고 주장하지 않고, 팀 안에서 제가 맡은 카메라 비전·웹 관제·서브 차량 구동의 인터페이스와 문제 해결을 설명하는 프로젝트입니다.”
