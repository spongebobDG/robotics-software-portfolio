## 해결하려던 문제

캠핑 환경에서 일산화탄소와 온습도 상태를 감지하고, ESP32에서 위험도를 판단해 사용자에게 전달하는 임베디드 안전 시스템입니다.

## 시스템과 기술

- ESP32/ESP32-C3, MQ-9, DHT11, OLED
- ESP-NOW/BLE 기반 데이터 전달 실험
- TensorFlow Lite Micro 기반 TinyML 모델 실험
- 3D 프린팅 케이스와 배터리 승압 효율 자료

메인 ESP32는 2초 주기로 데이터를 수집하고 최근 60개 샘플을 입력으로 사용합니다. ESP32-C3 수신기는 정상·주의·위험 상태에 따라 각성 주기를 달리하고, 두 노드는 AP 없이 ESP-NOW로 직접 통신합니다.

## 구현 근거

- MQ-9 센서 calibration과 CO PPM 판정 경로
- 온도·습도·가스 데이터를 포함하는 펌웨어 구조
- sliding input buffer와 TFLite Micro inference 코드
- 모바일 표시용 HTML 프로토타입

## MCU 제약에서 모델 구조를 바꾼 이유

초기 LSTM 모델은 약 174KB로, 센서·통신·OLED가 함께 동작하는 ESP32 환경에서 텐서 메모리 할당 문제가 발생했습니다. 장기 의존성보다 단시간의 농도 상승 패턴이 중요한 문제라고 다시 정의하고 1D-CNN으로 전환했습니다. KCC 논문과 지원 포트폴리오에는 약 10KB까지 줄인 결과를 보고했습니다.

다만 공개 저장소에는 개발 과정의 174KB 모델과 여러 소형 모델 artifact가 혼재하며, 논문의 174KB→약 10KB 비교를 한 번에 재현하는 학습 notebook과 release가 고정되어 있지 않습니다. 따라서 이 수치는 **논문 보고 결과**로 표시하고, 저장소만으로 재현 가능한 benchmark처럼 표현하지 않습니다.

## 안전 판단

- 15 PPM 미만: 센서 잡음 구간으로 보고 AI 결과를 사용하지 않음
- 15–50 PPM: AI 확률로 주의·위험 판단
- 50–400 PPM: 규칙이 최소 주의를 보장하고 AI가 위험으로 격상
- 400 PPM 이상: AI와 무관하게 위험 상태 강제

실제 CO 대량 수집의 위험 때문에 조기 경보 시간은 합성 데이터 기반 HIL 시뮬레이션으로 확인했습니다. 급성 누출 시나리오의 약 8.5초 조기 경보는 실환경 인증 성능이 아닙니다.

## 학술 성과

4인 개발팀의 팀장이자 제1저자로 「제한된 엣지 환경에서의 일산화탄소 조기 경보를 위한 경량 1D-CNN 기반 웨어러블 시스템 설계」를 작성했습니다. 멘토와 지도교수를 포함한 총 6명의 저자가 참여했으며, 한국컴퓨터종합학술대회(KCC 2026) 논문 심사를 통과해 포스터 세션에서 발표했습니다. 수상 실적은 없습니다.

## 현재 한계

- 저장소에 실험 버전과 중복 폴더가 함께 있어 기준 firmware를 명확히 분리해야 합니다.
- 모델 정확도·추론 지연·메모리 사용량의 재현 가능한 평가 보고서가 아직 없습니다.
- 실제 CO 기준 장비와 인증 시험을 통한 비교 검증은 수행하지 않았습니다.
- 안전 장치는 보조 수단이며 상용 CO 경보기나 인증된 안전 설비를 대체하지 않습니다.
