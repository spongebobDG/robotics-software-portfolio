# Dobot Vision Sorter

원본 저장소: [spongebobDG/dobot-vision-sorter](https://github.com/spongebobDG/dobot-vision-sorter)

## 해결하려던 문제

카메라가 정상·불량 블록을 검출하는 것만으로는 선별 작업이 완성되지 않습니다. 픽셀 좌표를 로봇 좌표로 변환하고, 물체의 회전각과 작업 범위를 검사하며, 잘못된 목표가 들어오면 로봇이 움직이지 않게 해야 합니다.

## 시스템과 기술

- Dobot Magician Lite, 고정 카메라, 공압 그리퍼
- YOLOv8 instance segmentation, mask 중심·회전각 추정
- Homography와 높이 보정 기반 camera-to-robot 변환
- 명시적 상태 기계와 one-object-per-scan 실행
- Python 단위 테스트 12개와 GitHub Actions

## 핵심 설계 결정

1. **Bounding box 대신 segmentation mask**를 사용해 중심과 회전각을 함께 계산했습니다.
2. Homography 계산에 사용하지 않은 별도 좌표로 보정을 검증하고, 기준 미달 파일은 실행 코드가 로드하지 않습니다.
3. 범위 밖 목표를 경계값으로 잘라 넣지 않고 원본 명령을 거부합니다.
4. 물체 하나를 옮길 때마다 다시 촬영해 과거 좌표가 다음 동작에 사용되지 않게 합니다.
5. 그리퍼 오류가 발생하면 성공으로 간주하지 않고 상태 전이를 중단합니다.

## 검증 결과

- Dobot Magician Lite 반복 pick-and-place **64.7초** 실기기 영상
- 하드웨어 없이 실행되는 단위 테스트 **12개**와 GitHub Actions
- 데이터 split 해시 검사, held-out calibration validation, 작업영역 reject 경로 자동 검증

## 프로토타입 감사

초기 버전에서 학습·검증 이미지 중복, 보정에 사용한 점으로 보정 오차를 평가한 문제, 범위 밖 좌표 clamp, 한 프레임 좌표 재사용 등 결과를 실제보다 좋아 보이게 만들 수 있는 문제 7개를 확인하고 수정했습니다. 데이터 누수가 있던 과거 mAP는 최종 성능으로 사용하지 않습니다.

## 현재 한계

- 누수를 제거한 새 데이터로 비전 정확도와 반복 배치 성공률을 다시 측정해야 합니다.
- 힘 센서가 없어 흡착 성공 여부를 소프트웨어가 직접 확인하지 못합니다.
- 실기기 영상은 파이프라인 동작 증거이며 정량 정확도 증거는 아닙니다.

## ROBOTIS 직무 연결

센서 좌표를 로봇 좌표로 옮기고, 변환이 신뢰할 수 없을 때 명령을 거부하는 프로젝트입니다. 휴머노이드에서도 인지 결과와 실제 관절 동작 사이의 인터페이스를 검증하고 실패 시 안전한 상태로 남기는 원칙이 중요하다고 생각합니다.
